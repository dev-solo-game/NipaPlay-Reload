多端播放稳定性保障方案 (绝不因重构出现播放问题)

核心原则：重构只改变上层“极简媒体库与设置”的 UI 呈现方式，底层的统一流媒体代理 (Local Streaming Proxy) 与跨平台播放器驱动层不仅完全保留，且被抽象为标准化桥接，确保 Windows、Android 手机、Android TV 等所有设备均零故障运行。

1. 夸克网盘防断流与防封禁：统一本地 Range 206 代理

夸克直链存在 15~60 分钟过期机制，且有高并发封控与 UA 校验。我们在各平台底层常驻轻量 HTTP 代理服务（`127.0.0.1:28282`）。无论 PC 端、手机端还是 TV 端，向播放器喂入的都是规范的本地 HTTP 链接。代理在后台负责：

  • 分段 Range 请求转发（毫秒级 Seek 不卡死）；
  • 静默无感 Token 刷新（即使看 3 小时电影也不会断播）；
  • 严格限速与平滑缓冲，杜绝触发网盘频控。

2. 跨平台播放内核解耦 (PlayerEngineBridge)

避免平台强绑定：

  • PC 桌面 (Windows/Linux)：使用 media_kit + libmpv，开启 D3D11VA 硬解，支持 4K 120Hz；
  • Android 移动端 & Android TV：自动选用 MediaCodec 硬件 Surface 解码，兼顾低发热与极低功耗；
  • tvOS / iOS：使用 VideoToolbox 硬件管线。

3. 电视端遥控器十字焦点 (Focus Navigation) 机制

在 Flutter 层面采用 `FocusScope` + `FocusNode` 统一焦点树管理：

  • 电视端默认将首个焦点自动锁定在“继续播放”胶囊按钮上；
  • 所有海报卡片与剧集卡片具备独立 Focus 监听，获得焦点时触发高对比度边框发光与放大 1.08 倍动画；
  • 按遥控器 OK 键直接起播，按返回键安全退回，绝不产生界面丢失或死循环。
